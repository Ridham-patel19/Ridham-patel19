## 🚀 Projects

### [Job Application Platform: Microservices](https://github.com/Ridham-patel19/JobAppMicroservice-K8s-)
`Java 21` `Spring Boot` `Spring Cloud` `RabbitMQ` `Docker` `Kubernetes`

A microservices system with Job, Company, Review and Auth services. Uses Eureka for service discovery, Spring Cloud Config Server, Spring Cloud Gateway, OpenFeign for inter-service calls, Resilience4j (circuit breaker, retry, fallback), RabbitMQ for async messaging, JWT authentication and Zipkin distributed tracing. Containerised with Docker and deployed to Kubernetes (Minikube).

### [Layer 7 HTTP Load Balancer (from scratch)](https://github.com/Ridham-patel19/MyLoadBalancer)
`Java 21` `Maven` `JUnit 5`

A load balancer and reverse proxy built on the plain JDK `HttpServer` and `HttpClient`, without Spring. Features path-based routing, a least-active-requests strategy (Strategy pattern), `AtomicInteger` connection tracking, a thread pool for concurrent handling, manual request/response forwarding with hop-by-hop header filtering and 502/503/504 error mapping.

### [LimitX: Rate Limiting Library](https://github.com/Ridham-patel19/RateLimiterLibrary)
`Java 21` `Spring Boot` `Maven` `JUnit 5`

A reusable rate-limiting library with **Token Bucket** and **Sliding Window** algorithms, annotation-based and endpoint-specific limits, request interception, HTTP 429 responses and thread-safe in-memory state. Tested with JUnit 5.

### Chess Engine and Online Chess App
`Java 21` `Spring Boot` `WebSocket / STOMP` `React`

A **domain-first** chess engine covering legal move generation, castling, en passant, promotion, check, checkmate and stalemate, with domain logic kept separate from the application and client layers. Extended from a console app to a REST and WebSocket backend with a React client (the frontend was AI-assisted) for real-time play. Working end to end locally; deployment is planned.

### FindYOU
`.NET` `PostgreSQL` `Hangfire`

An app for managing and discovering AI chat conversations, with bookmarks, likes, a dynamic feed, PostgreSQL full-text search and background jobs using Hangfire.
